# P25 Support Profile Target

## Required support tiers

### Supported-local

May include:
- package verifier,
- root Markdown archive hygiene,
- run-test-agent,
- inspect-run,
- flagship local coding-agent demo,
- memory seam fixture,
- daemon-safe local primitives,
- strict JSON boundary checks.

### Fixture-backed

May include:
- memory/runtime seam proof,
- local coding-agent fixture,
- provider route receipts with mock/local provider.

### Experimental

May include:
- daemon-safe queue scheduling beyond fixture scope,
- repair record display lanes,
- non-critical profile kit experiments.

### Deferred

Must include:
- cloud provider execution,
- native provider tool loops,
- full streaming provider loop,
- long-horizon autonomy,
- desktop control,
- V10 regional runtime,
- federation,
- mechanism/theory search.

## Required wording

Use phrases like:
- "supported-local"
- "fixture-backed"
- "deferred"
- "not production-cloud-ready"
- "no full autonomy claim"

Do not use phrases like:
- "complete autonomous platform"
- "cloud-ready"
- "fully verified V10 runtime"
- "federated/proof-governed complete"
unless those claims have direct evidence and are explicitly in scope.

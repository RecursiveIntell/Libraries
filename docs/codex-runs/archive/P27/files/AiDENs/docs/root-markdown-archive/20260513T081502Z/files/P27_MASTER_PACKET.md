## Strategic posture

P27 is not merely cleanup. It is a super-pass with a strict opening gate. Once the verifier/truth surface is repaired, it should advance real capability:

1. end-to-end supported-local provider path, at least mock and local Ollama where available;
2. durable run receipt store;
3. patch engine hardening;
4. coding-agent loop uplift;
5. memory-grounding seam hardening without shadow truth;
6. initial contracts/CLI megafile containment;
7. 11A semantic conformance labels and proof/check disclosures.

- V10 regional runtime implementation.
- V11 proof-carrying full runtime implementation.
- V12 regional protocol implementation.

# P09 — Canonical memory adapter over Forge, bridge, semantic-memory, and runtime

## Phase

Memory/runtime core

## Purpose

Turn `aidens-memory-kit` into a thin adapter over the canonical memory libraries.

## Why this pass exists

End-state law makes episodes identity-bearing and valid/recorded time part of meaning. MemoryRequired cannot be truthful until this exists.

## Depends on

P08

## Primary crates / surfaces

- `aidens-memory-kit`
- `aidens-contracts`
- `aidens-receipts`
- `aidens-boundary-kit`
- `aidens-cli`

## Artifact families introduced or hardened

- `semantic_memory_forge::EpisodeBundleV1`
- `semantic_memory_forge::ExportEnvelopeV3`
- `forge_memory_bridge::ProjectionImportBatchV3`
- `semantic_memory::MemoryStore`
- `knowledge_runtime::KnowledgeRuntime`

## Implementation steps

1. Import Forge exports through forge-memory-bridge.
2. Open/query canonical semantic-memory stores; do not write a local memory truth store.
3. Delegate temporal/as-of behavior to semantic-memory and knowledge-runtime APIs.
4. Make MemoryMode::Required require configured durable memory; Optional reports degraded if absent.
5. Emit memory write/query receipts linked to execution context.

## Acceptance gates

- Can insert a claim, supersede it retroactively, and answer both “what was true at valid time V” and “what did we believe at recorded time R”.
- MemoryRequired app fails doctor/run if no memory store is configured.
- No destructive update changes historical belief without supersession receipt.

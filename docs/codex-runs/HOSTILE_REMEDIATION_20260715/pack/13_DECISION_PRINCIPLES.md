# Decision principles

- Prefer a narrow truthful failure over broad fake compatibility.
- Disable an unsupported path rather than simulate it.
- Centralize contracts, not domain behavior.
- Preserve history and original bytes.
- Explicit policy beats default coercion.
- Typed capability/metric/state beats string conventions.
- Integration tests must cross actual crate boundaries.
- Source-bound receipts beat status prose.
- Optimize only after invariants freeze.

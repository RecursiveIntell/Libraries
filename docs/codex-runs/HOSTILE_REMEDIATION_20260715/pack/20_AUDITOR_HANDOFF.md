# Hostile auditor handoff

Provide original issue matrix, current integration tree, final workspace inventory, task/phase
receipts/logs, migration/rollback records. Do not provide implementer conclusions as authority.

For each original issue report open/partial/closed/superseded, exact current evidence, alternate
failure paths, new shadow state/duplicate authority/semantic widening/fake compatibility/false
completion/weak tests/missing rollback, and release-blocking status.

Independently verify stack-ids exclusivity, digest framing, strict ledger/head anchor, graph/governance/
codec failure semantics, backend substitution/metrics, queue races/leases, CI coverage, evidence
binding/cleanliness, and documentation provenance.

Verdict: `reject`, `conditional`, or `accept`.

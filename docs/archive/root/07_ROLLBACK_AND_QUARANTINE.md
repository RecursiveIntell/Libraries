# 07 — Rollback and Quarantine Plan

## Allowed changes

- `fib-quant/**`
- root `Cargo.toml` workspace member entry only
- root `Cargo.lock` if generated by Cargo
- `docs/compression/FIBQUANT_*.md`
- optional `.agents/skills/fibquant-paper-core/**`
- optional `.codex/hooks/fibquant_*.py`
- optional `.codex/hooks.json` if explicitly installed and reviewed

## Forbidden changes

- `semantic-memory/src/**`
- `turbo-quant/src/**`
- `AiDENs/crates/aidens-contracts/src/**`
- product app source
- generated compatibility shims
- any deletion of raw/canonical memory surfaces

## Rollback command set

If Codex violates forbidden-surface boundaries:

```bash
git diff --name-only
# inspect exact violation
# then revert forbidden paths only
git restore semantic-memory/src turbo-quant/src AiDENs/crates/aidens-contracts/src
```

If the crate does not compile and cannot be repaired safely:

```bash
git restore Cargo.toml Cargo.lock
rm -rf fib-quant
rm -f docs/compression/FIBQUANT_*.md
```

If hooks cause startup problems:

```bash
mv .codex/hooks.json .codex/hooks.json.disabled 2>/dev/null || true
mv .codex/hooks .codex/hooks.disabled 2>/dev/null || true
```

## Quarantine instead of guessing

When the paper math is ambiguous due to missing equation rendering, Codex must:

1. write `docs/compression/FIBQUANT_AMBIGUITY_REPORT.md`;
2. identify exact equation or table;
3. stop the phase;
4. avoid inventing a substitute.

# Implementation playbook

## What to do first

1. Apply the root pack exactly as written.
2. Regenerate the receipt.
3. Run the static gates.
4. Only then start DEMO-001.

## Demo playbook

1. Reuse existing wave fixtures; do not invent new schema families.
2. Stitch one demo bundle and one walkthrough README.
3. Add one validating test or script.
4. Link it from the root docs.

## Benchmark playbook

1. Freeze the questions before writing code.
2. Publish fixtures and expected outputs.
3. Emit one score sheet.
4. Keep the baseline honest and boring.

## Archive playbook

1. Move stale residue out of the root decision path.
2. Update the archive manifest.
3. Regenerate the receipt.

# Risk register

## Active risks

### R1 — front-door ambiguity resurfaces

If the restored docs drift from the receipt or from one another, reviewers will see multiple truths again.

### R2 — the demo becomes theatrical instead of evidentiary

A flashy demo that does not emit typed artifacts will weaken the whole stack.

### R3 — benchmark scope balloons into new architecture

If forge-bench becomes an excuse to reopen kernels, causal work, or remote exchange design, the finish line moves again.

### R4 — support scope gets overstated

The current hardening receipt covers the 17-crate lane, not every default-member crate.

### R5 — archive debt lingers long enough to confuse tools and humans

Logical supersession is already in place, but physical residue can still trip reviewers.

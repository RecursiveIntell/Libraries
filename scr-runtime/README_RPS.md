# Rock Paper Scissors - PySide6

A polished Rock Paper Scissors game built with PySide6.

## Features

- **Beautiful UI**: Modern dark theme with gradient backgrounds
- **Animated SVG Icons**: Custom SVG graphics for Rock, Paper, and Scissors
- **Score Tracking**: Keeps track of wins, losses, and ties
- **Visual Feedback**: Color-coded result display (green for win, red for loss, yellow for tie)
- **Smooth Animations**: Result display animates on each round
- **Hover Effects**: Buttons scale on hover and press
- **Reset Functionality**: Clear scores and start fresh

## Installation

```bash
pip install -r requirements.txt
```

## Running

```bash
python rock_paper_scissors.py
```

## How to Play

1. Click on Rock, Paper, or Scissors to make your choice
2. The computer will randomly select its choice
3. Results are displayed with visual feedback
4. Scores are updated automatically
5. Click "Reset Score" to start over

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a tie

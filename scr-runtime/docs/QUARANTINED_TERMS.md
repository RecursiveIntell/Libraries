# Quarantined Terms

These terms may appear only in historical or quarantine documentation, not in
production code, policies, schemas, crate docs, fixture semantics, or runtime
evaluator behavior.

Forbidden in production:

- FEUT
- EEG
- theta/alpha/gamma constants
- intelligence field
- P = NP
- Clay proof
- Riemann proof
- universal entropy law
- black-hole echo
- neuro-calibrated constants

Allowed production vocabulary:

- hazard
- uncertainty
- evidence
- authority
- containment
- integrity
- pressure
- decision
- receipt

Hostile checks in later phases must fail if quarantined terms appear in
production paths. Quarantine/history docs are the only allowed location for
these terms.

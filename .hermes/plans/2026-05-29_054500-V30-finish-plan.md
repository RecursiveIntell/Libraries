### 1.4 Replace In-Place UPDATE with Append-Supersede

**File:** `semantic-memory/src/episodes.rs`

Current behavior (lines 178-206): `UPDATE episodes SET ... WHERE episode_id = ?` — mutates row in place.

New behavior: When `update_episode` is called on an existing episode:
1. Read the existing episode row
2. Insert a NEW row with `episode_id = existing_id`, new `recorded_time = now()`, new payload
3. `UPDATE episodes SET superseded_by = new_fact_digest WHERE episode_id = ? AND recorded_time = old_recorded_time`
4. Emit `SupersessionReceipt`

Key code (replace lines 177-206):


### 2.3 Create Governed Encoding Path

**File:** `semantic-memory/src/quantize.rs` (new gated module)

```rust
#[cfg(feature = "turbo-quant-codec")]
pub mod governed {
    use quant_governor::{
        GovernancePolicy, GovernanceRequest, ContentType, AdmissibilityClass,
    };
    use scr_runtime_compression::{build_adapter, CodecDispatch};

    /// Encode a vector embedding through the governed compression pipeline.
    /// Returns (compressed_bytes, codec_profile, governance_receipt, raw_bytes_for_fallback).
    pub fn encode_governed(
        embedding: &[f32],
        dimensions: usize,
        policy: &GovernancePolicy,
    ) -> Result<GovernedEncodeResult, MemoryError> {
        let raw_bytes = bytemuck::cast_slice(embedding).to_vec();

        let request = GovernanceRequest {
            content_type: ContentType::Structured,
            size_bytes: raw_bytes.len() as u64,
            accuracy_requirement: 0.99,
            latency_tolerance_ms: 500,
            admissibility: AdmissibilityClass::Standard,
        };

        // Evaluate policy for codec selection
        let decision = policy.evaluate(request)
            .map_err(|e| MemoryError::Other(format!("governor: {e}")))?;

        // Build adapter with real codec dispatch
        let adapter = build_adapter::<Vec<u8>>(CodecDispatch::Governed {
            policy,
            request: GovernanceRequest {
                content_type: ContentType::Structured,
                size_bytes: raw_bytes.len() as u64,
                accuracy_requirement: if decision.codec == quant_governor::CodecProfile::Raw { 0.999 } else { 0.95 },
                latency_tolerance_ms: 500,
                admissibility: AdmissibilityClass::Standard,
            },
        });

        // Encode through adapter (exact fallback handled internally)
        let compressed = adapter.encode(&raw_bytes)
            .map_err(|e| MemoryError::Other(format!("encode: {e}")))?;

        Ok(GovernedEncodeResult {
            raw_bytes,
            compressed_bytes: compressed,
            codec_profile: decision.codec,
            exact_fallback: decision.exact_fallback,
            degradation_budget: decision.degradation_budget,
        })
    }
}
```

```rust
//! Unsafe syscall wrappers for check-runner process management.
//! Each function includes a // SAFETY: justification block.
#![allow(unsafe_code)]

/// Send SIGKILL to an entire process group.
/// SAFETY: pgid must be a valid process group ID owned by this session.
pub unsafe fn kill_process_group(pgid: i32) {
    unsafe { libc::killpg(pgid, libc::SIGKILL) };
}

/// Check if a process exists (kill with signal 0).
/// SAFETY: pid must be a valid process ID.
pub unsafe fn process_exists(pid: i32) -> bool {
    unsafe { libc::kill(pid, 0) == 0 }
}
```

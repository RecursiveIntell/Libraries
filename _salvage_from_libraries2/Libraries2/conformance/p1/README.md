
# P1 conformance

This directory tracks the post-v24 profile completion target for Privacy, Retention, Disclosure, and Redaction.

## Required checks
- schema/example publication is complete,
- at least one happy-path fixture exists,
- at least one blocked / degraded / exception fixture exists,
- owner placement is explicit,
- profile artifacts bind to existing base families rather than inventing shadow semantics.

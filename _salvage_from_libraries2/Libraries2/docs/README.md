- Read `PACK_README.md` first.
- Use `STATUS_DASHBOARD.md` for posture.
- Use `MASTER_ISSUE_MATRIX.md` for the full issue list.
- Use `CONFORMANCE_GATES.md` and `RELEASE_CHECKLIST.md` when deciding whether a snapshot is honestly release-facing.
- Use `11_BENCHMARK_PLAN.md` to drive the public proof package instead of reopening horizon work.

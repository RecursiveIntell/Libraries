# Closeout Scope and Non-Goals

## In scope

The next pass **should**:

- add the missing high-value v16–v20 artifact families required to make the current slices honest,
- deepen the existing evaluators without turning them into speculative orchestration engines,
- widen fixtures and tests,
- add missing IDs and schemas,
- add crate-local operating docs for the new crates,
- and update repo-level status/governance docs.

## Explicit non-goals

The next pass must **not**:

- pretend to fully implement all of v16–v20,
- create a new truth plane,
- silently promote advisory artifacts,
- wire the new crates into durable truth mutation paths,
- invent autonomous governance behavior,
- or perform giant crate refactors unless a file is becoming genuinely unmanageable.

## Version-specific boundaries

### v16
Do:
- shared replay,
- divergence reporting,
- treaty suspension,
- richer settlement receipts.

Do not:
- build global federation,
- build real networked trust-root exchange,
- or legalize peer count as proof.

### v17
Do:
- refuter-suite and stability-report gating,
- replayable fit-readiness logic.

Do not:
- build a giant search/planning engine,
- or claim that mechanism promotion is automatic.

### v18
Do:
- information-value-aware selection,
- explicit budget overload behavior,
- hypothesis-set linkage.

Do not:
- build a full scheduler,
- or claim optimal portfolio theory.

### v19
Do:
- amendment + semantic-diff + rollback linkage,
- archive/compaction evaluation,
- replay guarantees.

Do not:
- constitutionalize every markdown note,
- or automate governance beyond typed bounded flows.

### v20
Do:
- add `SelfHostingBuildReceiptV1`,
- generate interpreter/corpus/migration companion bundles,
- add human veto / meta challenge / rollback baseline.

Do not:
- legalize self-amendment,
- or pretend generated outputs are admitted.

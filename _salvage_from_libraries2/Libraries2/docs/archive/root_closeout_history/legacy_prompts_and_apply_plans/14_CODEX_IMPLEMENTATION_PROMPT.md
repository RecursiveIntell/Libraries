# Codex Implementation Prompt

Work against the current `zz5` snapshot using this pack as the active command set.

## Mission

Take the stack as far as possible **without reopening the architecture**.

## Non-negotiables

- Do not invent a new authority model.
- Do not create a second bundle contract when convergence is the goal.
- Do not let runtime, pilot, or control crates mutate truth directly.
- Do not silently widen, silently repair, or silently retry.
- Do not mark an issue complete without proof artifacts.

## Deliverable style

For each issue:

- say exactly what changed,
- show the crate/file list,
- list the acceptance criteria you satisfied,
- list the proof you produced,
- and list anything still open honestly.

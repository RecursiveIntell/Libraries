## Highest-pressure items
- **I006** `semantic-memory` — The canonical importer now deserializes typed payloads, but many logically required fields still arrive as Option<_> and are only enforced later. That keeps the importer structurally tolerant of malformed batches.
- **I007** `semantic-memory` — The importer still default-fills semantics like claim_state="active", freshness="current", preferred_open=false, and other canonical fields when the batch omits them. That turns malformed rows into plausible rows.
- **I011** `semantic-memory` — The unique preferred_open index for relation_versions keys only on (subject_entity_id, predicate, object_anchor, scope_namespace). It omits domain/workspace_id/repo_id, so distinct scoped relations can collide or be blocked incorrectly.
- **I015** `knowledge-runtime` — Temporal queries are still best-effort post-filtering over hybrid search, with downgrade warnings when temporal metadata is unavailable. This is the single largest remaining target-state gap.
- **I016** `knowledge-runtime` — Only namespace is pushed upstream. Domain/workspace_id/repo_id remain runtime-side warnings rather than real upstream enforcement.
- **I022** `agent-graph` — Graph events still carry legacy trace_id: String and attempt: u32 fields alongside canonical trace_ctx/attempt_id/trial_id.
- **I024** `agent-graph` — NodeStart/NodeEnd emissions still stamp legacy attempt: 0 at several sites even when canonical retry/trial lineage exists. That keeps legacy attempt counters misleading.
- **I026** `job-queue` — Public queue events and JobContext still expose legacy trace_id and attempt_count fields alongside canonical trace_ctx/attempt_id/trial_id.
- **I003** `forge-memory-bridge` — The old fake supersession bug is fixed, but the export/bridge contract still cannot preserve a real prior claim_version_id. Superseded lineage is therefore dropped rather than preserved.
- **I033** `semantic-memory-forge` — The forge crate now exists and its schema/doctrine layer is aligned, but it still lacks cross-crate proof tests that exercise forge bundle/export semantics through the bridge and memory-visible path.

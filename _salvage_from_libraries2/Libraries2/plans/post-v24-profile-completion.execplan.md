
# Post-v24 profile completion execution plan

## Thesis

This is the **finishing pass after the final general-purpose closeout**.
Do not invent a speculative `v25` while the repo still lacks the lawful profile overlays that the
terminal-horizon docs already call out explicitly.

## Phase order

1. freeze the no-v25 rule and the profile-family registry;
2. add shared profile IDs;
3. publish all profile schemas and examples;
4. land owner-crate profile modules;
5. land fixture corpus and conformance notes;
6. wire release-bar and documentation-truth updates;
7. validate pack truth.

## Hard rules

- No new workspace members.
- No shadow truth planes.
- No hidden vendor caveats.
- No permanent privacy or locality exception by inertia.
- No approval, pager, or recertification semantics that live only in external tools.
- No hazard catalog without monitor and mitigation bindings.
- No profile marketed as a new base-spec wave.

## Definition of success

The pass succeeds when the repo has a truthful, additive, implementation-ready overlay for the
named post-v24 profile lanes.

It does **not** require full production behavior for every surface, but it **does** require:
- owner placement,
- schema coverage,
- example coverage,
- fixture coverage,
- explicit integration points,
- and a release bar that names the remaining local doctrine honestly.

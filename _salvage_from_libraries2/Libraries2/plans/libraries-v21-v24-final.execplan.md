# Libraries v21–v24 final closeout execution plan

## Thesis

This is the **final general-purpose closeout lane** for the stack.
Do not invent a speculative v25 while the repo still lacks the lawful owner crates, schemas, examples,
fixtures, and integration seams for v21–v24.

## Phase order

1. freeze vocabulary, owners, and terminal-horizon rule;
2. add the four new owner crates;
3. publish all v21–v24 schemas and examples;
4. land fixture corpus and conformance notes;
5. wire integration snippets into `stack-ids`, `contract-schema-gen`, `semantic-memory`,
   `knowledge-runtime`, `verification-*`, and `llm-tool-runtime`;
6. prove one bounded vertical slice per wave;
7. close on release bar, risk register, and pack-truth checks.

## Hard rules

- No ambient privilege.
- No score-only release approval.
- No untyped emergency folklore.
- No live effect without typed preflight, commit, observation, and compensation semantics.
- No delegated action without a typed authority chain and lease validity.
- No deployability decision without typed assurance and monitoring objects.
- No incident handling that cannot emit replay and postmortem artifacts.
- No v25 design inflation in this pass.

## Definition of success

The pass succeeds when the repo has a truthful, additive, implementation-ready overlay for v21–v24.

It does **not** require full production behavior for every surface, but it **does** require:
- owner crates,
- schema coverage,
- example coverage,
- fixture coverage,
- explicit integration points,
- and a release bar that names the remaining profile-level work honestly.

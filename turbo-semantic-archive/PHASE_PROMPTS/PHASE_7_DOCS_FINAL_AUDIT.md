# Phase 7 — Docs, Cleanup, Final Audit

## Goal

Make the integration usable, honest, and auditable.

## Required changes

1. Docs:
   - feature flag usage;
   - repo layout requirement;
   - config examples;
   - shadow-mode explanation;
   - approximate search disclosure;
   - evaluation report interpretation;
   - rollback instructions.

2. Cleanup:
   - remove stale local experiments;
   - no duplicate docs that teach old behavior;
   - no dead feature flags;
   - no failing scripts.

3. Final hostile audit:
   - check no shadow codec;
   - check no default promotion;
   - check raw embeddings remain authoritative;
   - check all approximation is disclosed;
   - check tests and scripts;
   - check unresolved risks.

4. Final report:
   - changed files;
   - test commands/results;
   - final capability state;
   - exact limitations;
   - next pass recommendations.

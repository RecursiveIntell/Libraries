# Claim Boundary

Allowed public claims for this alpha:

- Rust crates provide shared KV pool manifests, receipts, exact fallback, q8 key experiments, and deterministic synthetic tests.
- Shape V2 contracts are implemented in `quant-codec-core`.
- The Python sidecar is optional, alpha, and bulk-oriented.
- Tier 0/Tier 1 harnesses emit JSON artifacts under `.codex-runs/`.

Claims that require future local receipts before use:

- fixed memory reduction;
- quality preservation on real models;
- throughput or latency improvement;
- serving runtime compatibility;
- broad Python tensor framework support;
- adaptive routing completion.

Attribution:

This workspace is an independent Rust research-to-implementation effort inspired by PolyKV-style shared compressed KV-cache pool ideas. It is not the original authors' reference implementation and does not claim affiliation with the PolyKV paper authors.

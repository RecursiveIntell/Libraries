# Phase 10 — Hostile-Auditor Handoff

## Objective

Produce final evidence package and next-pass boundary.

## Required actions

1. Write `changed_files.txt`.
2. Write `commands_run.log`.
3. Write `validation_results.md`.
4. Write `risk_register.md`.
5. Write `rollback_plan.md`.
6. Write `remaining_delta.md`.
7. Write `final_audit_report.md` using required handoff format.

## Acceptance gate

Final handoff exists and does not claim completion beyond evidence.

## Phase-boundary report must include

- files inspected;
- files changed;
- commands run;
- tests/checks passed/failed/skipped;
- source-of-truth boundary status;
- unresolved blockers;
- rollback notes.

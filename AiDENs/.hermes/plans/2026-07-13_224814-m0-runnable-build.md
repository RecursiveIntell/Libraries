## 3. M0 build steps (this session)

Each step ends with a receipt: build artifact, captured test summary, or a saved NDJSON.

### Step 1 — Workspace skeleton
- Create directory and `Cargo.toml` workspace.
- Path-depend on `boundary-compiler`, `stack-ids`, `bitemporal-runtime`, `claim-ledger`. **`agent-graph` is consumed but only for type-level integration points in M0** to keep the surface small; the full graph engine is not used in M0.
- `AGENTS.md`, `README.md`, `docs/adr-0001-boundary-and-canonical-owners.md`.
- Receipt: `cargo metadata --no-deps` exits 0, member list captured.

### Step 2 — `recursive-agent-contracts`
- Typed: `RunSpecV1`, `StepSpecV1`, `RunStartedV1`, `RunFinalizedV1`, `StepCompletedV1`, `ReceiptV1`, `AuthorityLineageEntryV1`, `PermitV1`, `ToolManifestV1`, `EffectTargetV1`, `ReceiptChainDigestV1`.
- All `Serialize/Deserialize`, all `boundary-compiler` JCS-compatible.
- `from_json_refined(&[u8])` returns `Result<Self, ContractError>` for every type (rejects on `BoundaryCompilerError`).
- Tests: round-trip; boundary-compiled digest stable; malformed boundary rejected with structured error.

### Step 3 — `recursive-agent-ledger`
- `Ledger` owns a chain of `ReceiptV1`, computes `chain_digest = blake3(prev_digest || canonical(receipt))`.
- `append(&ReceiptV1) -> Result<ReceiptRef, LedgerError>` is append-only; no overwrite.
- `verify(&Path) -> Result<ChainVerification, LedgerError>` rewalks the chain and returns the count + first divergence (if any) + final digest.
- `ArtifactStore` for content-addressed payloads (blake3-keyed files under `artifacts/`).
- Tests: chain stays consistent under restart; tampering detected; missing file detected; large payload not inlined.

### Step 4 — `recursive-agent-policy`
- `PolicyEngine` (M0): static allowlist of `(tool_name, max_invocations, max_arg_bytes)`.
- `PermitV1` is a family-qualified ID; consumption is **durable** through the ledger (one-shot recorded).
- `AuthorityLineageBuilder` requires `[request, plan, tool, effect]` in that order; verifier rejects incomplete lineage.
- Tests: deny by default; lineage rejection; permit replay rejected via durable ledger marker.

### Step 5 — `recursive-agent-tools`
- `ToolManifest` registry with two tools: `echo`, `time_now`.
- `echo` is pure: takes a string, returns it as an artifact reference, no I/O.
- `time_now` returns the wall clock; refuses to run unless caller passes `frozen_clock: Option<DateTime<Utc>>` (refuses implicit wall-clock for reproducibility).
- All argument validation through `boundary-compiler` JCS-typed schemas.
- All outputs are receipt-referenced artifacts (not inline in receipts).

### Step 6 — `recursive-agent-graph`
- Define a minimal typed run DAG: `Request -> Plan -> [ToolStep1, ToolStep2] -> Aggregate -> Finalize`.
- No dynamic `agent-graph::Engine` invocation in M0; we build our own deterministic walk to keep the surface narrow and the receipts simple. We **import `agent-graph` types** for downstream graph run bundles but do not depend on its scheduling.
- Every node emits exactly one `ReceiptV1` before, during, and after execution.

### Step 7 — `recursive-agent-cli`
- `ra run --spec <path> [--frozen-clock <iso>]` → executes M0 graph, writes `runs/<id>/`, prints receipt summary.
- `ra verify <run-dir>` → walks chain, prints pass/fail, exits non-zero on first divergence.
- `ra replay <run-dir>` → re-emits recorded outputs offline; prints divergence report.
- `ra doctor` → prints binary version, library versions, supported tools, deterministic clock status.
- All commands print `--mode recorded` and refuse to call any provider (no env-based backdoors).

### Step 8 — Tests + receipts
- Unit tests per crate, including boundary-rejection tests.
- Integration test: `cargo run -- run fixtures/hello-run.json` produces receipts; `cargo run -- verify <run-dir>` passes; tampering a byte in the chain fails verification with a precise report.
- Save raw NDJSON under `docs/receipts/`.

### Step 9 — `release-gate.sh` (this session)
- `cargo fmt --all -- --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace --locked --no-fail-fast`
- `cargo run -p recursive-agent-cli -- doctor`
- `cargo run -p recursive-agent-cli -- run fixtures/hello-run.json` (one-shot)
- `cargo run -p recursive-agent-cli -- verify <run-dir>`
- A negative tampering test in CI script: flip a byte, expect non-zero exit.
- Capture the full transcript under `docs/receipts/`.

# P28 Support Profile Target

## Supported after successful P28

- Local AgentSpecV1 validate/doctor/new.
- Supported-local mock/local Plan/Act/Verify path.
- Supported-local repo read/list/stat/search with v11A material operation receipts.
- Supported-local patch propose/apply/check with sandbox/rollback/receipt hardening.
- Local run bundle inspection with immutable attempt/content addressing.
- Boundary compiler profiles for declared structured inputs/outputs.
- Proof debt/waiver/degradation visibility on declared paths.
- v11A conformant core only for declared local agent path if all gates pass.

## Reserved / draft only

- v11B graph/region/subtraction runtime: draft/advisory only.
- v11C self-hosting/federation/mechanism: reserved only.
- Agency preservation: local classification scaffold only unless receipts/policy/reference gates are added.

## Explicit non-claims

- production cloud readiness
- hosted provider native tool loop readiness
- broad autonomy readiness
- production daemon authority
- full v11+ release candidate
- canonical memory/governance/kernel/provider/schema ownership

## Support downgrade triggers

Downgrade to `v11A-draft` if:

- any P0 bug remains open without release-blocking quarantine;
- material done states can occur without receipts;
- waiver is treated as proof;
- degraded checks aggregate to exact status;
- boundary repairs can change treatment without receipt;
- run bundles can silently overwrite evidence;
- final package manifest cannot be verified against uploaded sidecars.

# V10+ Design Track Brief

## Recommendation

Start designing V10+ now, but do not implement V10+ in P25.

## Why

P24/P25 close the current AiDENs supported-local seam. V10 changes runtime geometry and should be handled as a separate architecture track.

## V10 scope

V10 should define:
- storage graph,
- retrieval graph,
- inference graph,
- repair graph,
- control/receipt graph,
- right-graph compilation,
- time-aware incremental recomputation,
- syndrome/residual surfaces,
- oracle slices,
- nuisance-state modeling.

## V11 scope

V11 should define:
- executable semantics,
- reference interpreters,
- exact/approximate correspondence,
- proof obligations,
- semantic conformance,
- learned-component boundaries.

## V12 scope

V12 should define:
- small communicating regions,
- typed region protocols,
- convergence/damping/stop rules,
- oscillation artifacts,
- local repair before global rebuild.

## Later scope

V13+ may cover:
- lawful subtraction,
- intervention/counterfactual experiments,
- attested exchange,
- federation/treaties,
- mechanism/theory runtime.

## Hard separation rule

P25 may include this design brief. P25 must not implement V10+ runtime geometry.

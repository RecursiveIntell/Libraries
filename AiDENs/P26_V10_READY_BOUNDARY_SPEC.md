# P26 V10-Ready Boundary Spec — Design Only

## Purpose

P26 should prepare names and seams for V10 without implementing V10.

## Design-only concepts

- Storage graph
- Retrieval graph
- Inference graph
- Repair graph
- Control/receipt graph
- Region descriptor
- Convergence policy
- Oracle-slice descriptor
- Nuisance-state descriptor

## P26 allowed work

- Document these as future boundaries.
- Ensure P26 agent evidence does not collapse them.
- Add tests that forbid claiming V10 support.

## P26 forbidden work

- No regional runtime.
- No hypergraph kernel implementation.
- No learned scorer promotion.
- No federated settlement runtime.
- No mechanism/theory search implementation.

## Working thesis

v10 makes runtime geometry explicit. v11+ makes that geometry **constitutionally executable**.

The stack becomes a **typed artifact runtime** where every material action is a state transition over canonical artifacts; every operator declares semantic effects; every approximation is challengeable; every contradiction has a typed surface; every deletion/summary is lawful subtraction; every meaningful execution condition emits evidence; and future law changes can eventually be compiled, simulated, checked, vetoed, and admitted.

The target is not “more AI features.” The target is a stack that can **testify**.

## Why A/B/C

The spec is too deep for one monolith without either losing force or becoming unreadable.

- **v11A** freezes the *constitutional microkernel*: artifacts, semantics, operator effects, proof obligations, execution receipts, boundary compiler, and reference interpreters.
- **v11B** freezes the *recursive runtime*: regions, right-graph compilation, convergence, message passing, lawful subtraction, repair, local quarantine, and causal intervention packages.
- **v11C** freezes the *future-admission skeleton*: self-hosted spec bundles, federation/treaties, mechanism/theory search, agency-preservation artifacts, external admission, and generated conformance.

The split is staged, not watered down. v11A should be buildable first. v11B should be impossible to implement lawfully without v11A. v11C should prevent future retrofit hell by reserving the right artifact shapes early.

## What v11+ adds beyond v10

| Prior surface | v11+ upgrade |
|---|---|
| Distinct runtime graphs | Right-graph compiler law with graph-declaration receipts and misuse gates. |
| Small communicating regions | Canonical region contracts, boundary messages, receipts, replay slices, and convergence reports. |
| Evidence bundles | Full typed artifact lifecycle with semantic product carriers and proof-economy state. |
| Execution evidence | Execution receipts become part of artifact meaning, not logs. |
| Causal attribution | Interventional packages require treatment/outcome/confounder/refuter/replay law. |
| Structured outputs | Boundary compiler law replaces tolerant parsing. |
| Repair | Contradictions emit syndrome/residual/repair/quarantine artifacts; repair has blast-radius law. |
| Compression/summarization | Lawful subtraction with support cores, removal frontiers, invariant receipts, and historical-loss budgets. |
| Reference semantics | Reference interpreters and generated conformance corpora become release-blocking. |
| Future evolution | Spec bundles, normative ASTs, generated schemas, amendment simulation, and human veto are seeded. |

## Non-goals

This pack does not claim the code already meets the v11+ bar. It is a target-state draft.

This pack does not reopen v6-v10 authority doctrine. It extends it.

This pack does not require full federation, full mechanism discovery, or full constitutional self-hosting to ship in v11A or v11B. It requires the stack to stop designing in a way that would make those future capabilities semantically impossible.

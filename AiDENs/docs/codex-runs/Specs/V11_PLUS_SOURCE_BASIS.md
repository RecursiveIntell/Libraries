## 5. Core synthesis conclusions

### 5.1 The strongest invariant is truthful artifacts

Across the corpus, the repeated conclusion is that the stack should not center on runtime state, model answers, or storage rows. It should center on typed artifacts: episode bundles, evidence bundles, execution receipts, verification plans, proof profiles, witnesses, certificates, syndromes, residuals, repair records, subtraction receipts, admission envelopes, and eventually mechanism/theory bundles.

### 5.2 Execution context is meaning-bearing

Retries, deadlines, queue hops, provider routes, truncation, widening, replay lineage, and attempt-family identity are not telemetry. They can change whether an output is reproducible, comparable, promotable, or contaminated. v11+ therefore treats execution evidence as part of artifact semantics.

### 5.3 Bitemporality remains non-negotiable

Valid time and recorded time are separate semantics. Every truth-bearing artifact and every queryable claim-like state must preserve those coordinates or explicitly degrade.

### 5.4 The runtime needs reference semantics before it needs more cleverness

The research points repeatedly to reference interpreters and conformance corpora as the anti-drift mechanism. v11+ requires reference behavior for bitemporal query semantics, import/bridge invariants, view widening, boundary compilation, repair/subtraction invariants, region protocols, and proof-profile eligibility.

### 5.5 The boundary is a compiler front, not a parser

Structured-output ingestion, JSON parsing, patch application, schema migration, tool outputs, and generated artifacts should be governed as language boundaries. Repairs require receipts and treatment-integrity checks.

### 5.6 Regions are the default execution unit

Small communicating regions preserve locality, replayability, bounded cost, and contradiction containment. v11+ therefore moves region protocol law from “future geometry” into the v11B release line.

### 5.7 Inference and subtraction are dual operator families

The end-state materials converge on a stronger thesis: the system must not only build support; it must lawfully remove, compact, summarize, and minimize while preserving declared invariants and history budgets. v11B therefore treats lawful subtraction as a first-class peer to recursive inference.

### 5.8 Future capabilities need hooks now

Federation, mechanism search, external admission, constitutional self-hosting, and agency preservation cannot be retrofitted cleanly if the artifact model is too narrow. v11C reserves those hooks and defines early artifact law without requiring full implementation immediately.

## 6. Drafting posture

This pack is intentionally aggressive about what v11+ should introduce conceptually and conservative about what v11A/B must fully implement immediately.

The key line is:

> v11+ should define the constitutional runtime law now, while allowing implementation to progress through A, B, and C release bars.

# P25 Master Packet

## Run name

**P25 — Root Hygiene, Phase-Gate Enforcement, Release Convergence, and Flagship Local Agent Demo**

## Mission

Convert the prior-run baseline into a cleaner, more reliable supported-local AiDENs release surface by closing process, packaging, and evidence seams.

P25 is not about adding broad new capabilities. It is about making the current capability harder to misrepresent, easier to audit, and safer for Codex to work on.

## Hard doctrine

1. AiDENs is a **consumer/orchestration/profile/operator layer** over canonical libraries.
2. AiDENs must not invent canonical truth, memory, execution, verification, repair, schema, or runtime semantics.
3. `z.py` is operator-local packaging/certifier tooling.
4. `z.py` may only be touched for the root Markdown archive feature and associated evidence/reporting.
5. Phase gates are blocking operator approvals.
6. The every-other-phase gating cadence is allowed only because each gate validates all prior work since the previous gate.
7. No silent widening.
8. No compatibility shims.
9. No fake completion.
10. V10+ remains design-only.

## Target final claim

> AiDENs is a cleaner supported-local, evidence-bearing Rust agent/profile/operator framework with deterministic package hygiene, machine-checkable phase gates, root-doc noise control, a replayable flagship local coding-agent demo, and strict support-tier disclosure.

## Forbidden final claim

> AiDENs is now a complete autonomous/cloud/federated/proof-governed/V10+ runtime.

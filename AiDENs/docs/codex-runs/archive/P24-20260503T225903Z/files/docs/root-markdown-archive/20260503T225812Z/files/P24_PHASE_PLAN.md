# P24 phase plan

This plan is deliberately narrow: finish V9 seam consumption and runnable local product slices. Do not use this pass to build the whole V10+ horizon runtime.


## Phase 00 — Preflight hostile audit and source-basis freeze

**Goal:** Prove the package, sidecars, source tree, research basis, active docs, and verifier environment before modifying code.

**Required actions:**

1. Start from a clean tree and record the input package/report hashes.
2. Make the smallest code/doc changes that satisfy the phase goal.
3. Add or update tests before marking the phase complete.
4. Emit `AiDENs/handoffs/p24/PHASE_00_REPORT.md` with commands, changed files, artifacts, failures, and unresolved risks.
5. Re-run the global invariant checks before continuing.

**Global invariants for this phase:**

- AiDENs remains consumer-only for canonical truth, memory, identity, verification, repair, and execution semantics.
- Support labels must match runnable evidence.
- Any degradation must be explicit in the emitted artifact.
- No local display digest may be treated as canonical identity.

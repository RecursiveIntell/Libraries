# P23 Evidence and Reporting Requirements

Every phase report must include:

- phase objective,
- files changed,
- commands run,
- gate outputs,
- cargo status,
- package/replay status where relevant,
- capability progress where relevant,
- invariant revalidation,
- unresolved risks,
- stop/continue decision.

Final audit report must include:

- actual capability shipped,
- exact package role table,
- package hashes and manifest counts,
- self-replay result,
- support-tier changes,
- known limitations,
- hostile auditor notes,
- next recommended pass.

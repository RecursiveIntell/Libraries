# Phase 00 — Operator Arbitration, Source Basis, and Baseline Plan

## Objective

Establish execution context, repo/source basis, permits, available tools, expected paths, and phase plan before modifying code.

## Required actions

- Identify repo root.
- Confirm sibling canonical crate path assumptions.
- Read `Cargo.toml`, `AGENTS.md`, and P20 docs.
- Emit a Turn/Run Arbitration Artifact in `docs/p20/reports/PHASE_00_REPORT.md`.
- Record chosen action and rejected alternatives.
- Do not edit source code except to install overlay if needed.

## Acceptance gate

Phase report exists and includes source basis, tool/capability assumptions, risks, and Phase 1 preconditions.

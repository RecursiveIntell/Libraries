# P20.2 Manual Phase Injection Prompts

Use these between phases.

For every phase:

1. paste `GLOBAL_PRE_PHASE_INVARIANT_REVALIDATION.md`;
2. paste the matching `PHASE_XX_*_INJECTION.md`;
3. require Codex to state whether the phase can proceed.

The global injection is necessary but not enough. The phase-specific prompt catches the local failure mode.

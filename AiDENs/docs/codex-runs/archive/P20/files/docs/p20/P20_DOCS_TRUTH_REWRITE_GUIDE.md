# P20 Documentation Truth Rewrite Guide

## Replacement rule

Replace stale Codex-run prose in active root docs with current project truth.

## Active docs must answer

- What is AiDENs?
- What is supported in v0.1?
- What is delegated to canonical crates?
- What is partial/scaffold/deferred?
- How do I run verification?
- What are known limitations?

## Forbidden language unless proven

- production-ready
- complete
- fully implemented
- supports all providers
- native tool calling
- bitemporal support complete
- full repair runtime
- full federation
- full mechanism runtime
- autonomous scheduler complete

## Required evidence for “supported”

- code path;
- test or fixture;
- docs;
- scanner or audit evidence;
- final report entry.

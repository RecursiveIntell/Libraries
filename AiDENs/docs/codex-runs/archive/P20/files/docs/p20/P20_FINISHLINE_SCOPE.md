# P20 Finishline Scope

## Scope statement

P20 finishes **AiDENs v0.1 as a truthful orchestration layer**, not the entire long-horizon provenance runtime.

The finish line is:

- build-certified workspace;
- truthful docs/status;
- canonical crate delegation proven by tests/scanners;
- provider capability honesty;
- one working runner vertical slice;
- agency/influence governance at the AiDENs boundary;
- reference-interpreter closeout or honest demotion;
- final audit bundle.

## Explicit non-goals

P20 must not attempt to finish:

- full regional fixpoint runtime;
- full federated claim settlement runtime;
- full mechanism/theory search runtime;
- complete desktop daemon lifecycle;
- all cloud provider native tool loops;
- autonomous recurring scheduler beyond documented v0.1 support;
- cryptographic attestation/signing beyond available canonical crates;
- full JSON Schema engine if the existing validator is only a subset.

## Readiness labels

| Label | Meaning |
|---|---|
| `supported` | Executable, tested, documented, and verified in P20 |
| `adapter/delegated` | AiDENs exposes/wires a canonical crate capability; canonical crate owns semantics |
| `partial` | Some behavior exists but limitations are explicit |
| `scaffold` | Structure exists but not an executable supported feature |
| `deferred` | Not part of v0.1 finish line |
| `removed` | Removed from active surface |
| `failed/quarantined` | Found unsafe/ambiguous; isolated pending later repair |

## Done definition

P20 is done only if all phase gates in `P20_ACCEPTANCE_GATES.md` pass, final audit artifacts exist, and no unsupported feature is presented as supported.

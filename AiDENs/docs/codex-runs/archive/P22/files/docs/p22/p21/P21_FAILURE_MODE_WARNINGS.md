# P21 Failure-Mode Warnings for Codex

Codex tends to fail this project by:

- optimizing for momentum after one test passes;
- turning examples into fake support claims;
- replacing missing fixtures with deleted tests;
- inventing local DTOs for canonical concepts;
- treating provider fallback as provider support;
- wiring a CLI path that bypasses runner receipts;
- treating agency policy as text instead of runtime gating;
- copying Recall-specific behavior into AiDENs core;
- creating compatibility shims instead of strict boundaries;
- claiming final pass without release archive replay.

Do not do these.

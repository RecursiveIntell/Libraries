# P22 Ownership / Source-of-Truth Map

| Concern | Canonical owner | AiDENs role | Must not |
|---|---|---|---|
| IDs, digests, trace primitives | `stack-ids` | consume/display/reference | invent new canonical digest law |
| Raw evidence/export truth | `semantic-memory-forge` | route/export/report | reinterpret raw evidence as AiDENs truth |
| Bridge transform | `forge-memory-bridge` | call/verify package surfaces | become policy engine |
| Queryable memory projection | `semantic-memory` | wire optional profile views | create shadow memory database |
| Runtime retrieval/planning | `knowledge-runtime`, AiDENs plan/runtime kits | direct and disclose degradation | silently widen scope |
| Tool runtime receipts | `llm-tool-runtime`, AiDENs tool/runner kits | expose tool truth, permits, receipts | fake executable/tool support |
| Verification policy/control | `verification-*`, AiDENs governance kit | route policy reports | promote scores into truth |
| Recursive/kernel proof | `recursive-kernel-*`, `constraint-compiler` | expose guarded integration | implement local substitute kernel |
| Packaging/certification | `z.py` | normalize, certify, package | become source of domain truth |
| Codex run history | `docs/codex-runs/archive/**` | preserve and index | act as current instruction surface |

## AiDENs non-authoritative wrappers

Display DTOs, package manifests, archive manifests, support reports, generated project files, examples, and docs are non-authoritative unless they reference canonical owner artifacts or executable proof.

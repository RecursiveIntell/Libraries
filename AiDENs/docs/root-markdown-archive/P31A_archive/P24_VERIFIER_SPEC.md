# P24 verifier specification

## Required script

Create `AiDENs/scripts/p24_verify.sh`.

## Behavior

- `set -euo pipefail`
- accepts repo root argument, default `.`
- creates `target/p24-verifier/`
- runs each assertion under a timeout
- writes stdout/stderr separately
- writes JSON receipt
- exits nonzero if any required gate fails

## Pruning

All recursive scans must ignore:

- `.git/`
- `target/`
- `target-*/`
- `docs/codex-runs/archive/`
- package outputs: `*.zip`, `*.7z`, generated sidecars
- `handoffs/p20`, `handoffs/p21`, `handoffs/p22`, `handoffs/p23` unless explicitly auditing history
- generated cargo fingerprint/build artifacts

## Required checks

- no legacy zip wrapper ownership regression
- script references resolve and terminate
- no local canonical type substitutes
- no local canonical digest law
- no fake completion claims
- no scaffold promoted in support profile
- docs match cargo workspace members
- schema generation scope is local-display only unless generated by canonical owners
- wrapper backpointers present for display DTOs
- p24 run-bundle schema exists and validates fixture
- package self-replay passes

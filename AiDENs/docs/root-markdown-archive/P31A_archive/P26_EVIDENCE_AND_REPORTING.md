# P26 Evidence and Reporting Requirements

Every phase report must contain:

- phase objective;
- changed files;
- commands run;
- command results;
- evidence artifacts emitted;
- invariant revalidation;
- unresolved risks;
- support claim changes;
- next-phase preconditions.

Final artifacts:

- `P26_STATUS_EVIDENCE_MANIFEST.json`
- `docs/p26/P26_FINAL_AUDIT_REPORT.md`
- `docs/p26/P26_KNOWN_LIMITATIONS.md`
- `handoffs/p26/FINAL_AUDITOR_HANDOFF.md`
- `SUPPORT_PROFILE.md`
- `STATUS.md`
- `docs/codex-runs/CURRENT_RUN.md`
- `docs/codex-runs/CODEX_RUN_INDEX.md`
- strict package sidecars

Evidence must be machine-readable where possible and human-readable where necessary.

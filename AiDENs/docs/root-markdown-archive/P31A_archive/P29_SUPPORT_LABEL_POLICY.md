# P29 Support Label Policy

## Allowed

```text
p29-package-repaired
p29-supported-local-plus
v11A-local-release-candidate
v11B-executable-seed
v11C-reserved-only
```

## Disallowed

```text
v11B-complete
v11C-complete
production-cloud-ready
broad-autonomy-ready
canonical-memory-truth-owner
canonical-governance-truth-owner
canonical-kernel-truth-owner
canonical-provider-contract-owner
canonical-schema-generation-owner
```

## Required disclosure

All user/operator-facing docs must state:

```text
P29 reaches v11A local release-candidate status only for the declared supported-local path, and seeds v11B executable surfaces without claiming v11B completion.
```

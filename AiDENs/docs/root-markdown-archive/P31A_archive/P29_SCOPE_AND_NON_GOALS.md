- P28 evidence/package repair.
- Current-run identity repair.
- Final verifier and package self-replay.
- Manifest path validation.
- Critical/high Claude audit bug closure where feasible.
- v11A local release-candidate path.

## Out of scope

- Full v11B completion.
- v11C completion.
- Production cloud readiness.
- Broad autonomy readiness.
- Complete repair of all 200 audit bugs if not feasible in one pass.
- Full audit of forge-pilot, effect-runtime, verification pipeline, federation, attestation, authority delegation, recursive kernel.
- Replacing canonical sibling owners with AiDENs local truth.

## Quarantine rule

If a high-risk item cannot be fixed safely, quarantine it with:

- issue ID,
- current behavior,
- why it remains unsafe,
- support label impact,
- next-pass requirement.

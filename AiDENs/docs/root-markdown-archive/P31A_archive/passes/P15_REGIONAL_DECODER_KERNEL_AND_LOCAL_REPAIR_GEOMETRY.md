# P15 — Regional decoder kernel, right-graph law, and local repair geometry

## Phase

Advanced runtime geometry

## Purpose

Implement the first bounded hypergraph/factor-region kernel after the evidence/memory/control substrate is lawful.

## Why this pass exists

The decoder and region research says the system needs right-graph compilation, small communicating regions, convergence governance, syndrome/residual artifacts, oracle slices, and local repair.

## Implementation steps

1. Define distinct graph kinds: storage, retrieval, inference, repair, control. Forbid using storage graph directly as inference graph.
2. Compile small regions from memory/projection evidence with typed node, edge, hyperedge, factor, nuisance, and boundary definitions.
3. Implement bounded message passing with damping, residual threshold, iteration cap, and oscillation receipt.
4. Add exact-on-small oracle slice for small acyclic/low-treewidth regions or deterministic constraint subsets.
5. Route contradictions by syndrome to local repair before global rebuild.

## Acceptance gates

- A synthetic contradiction emits SyndromeV1 and local repair candidate instead of global recompute.
- Loopy propagation with non-convergence emits ConvergenceReportV1 and degraded state.
- Oracle slice agrees with approximate path on small gold fixtures or records bounded disagreement.

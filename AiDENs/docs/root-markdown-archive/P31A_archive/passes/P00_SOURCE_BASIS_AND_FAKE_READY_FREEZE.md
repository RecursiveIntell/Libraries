# P00 — Source-basis lock, fake-ready freeze, and repo hygiene gate

## Phase

Foundation / honesty

## Purpose

Freeze the source basis and make it impossible to claim readiness while scaffold-only or fake-ready surfaces remain hidden.

## Why this pass exists

The current repo already contains good warning signs and scripts, but several docs are stale and many crates are still scaffold-only. Codex needs a hard current-state baseline before it changes behavior.

## Depends on

None. This is the baseline lock.

## Primary crates / surfaces

- `workspace root`
- `scripts`
- `docs`
- `aidens-testkit`

## Artifact families introduced or hardened

- `SourceBasisLockV1`
- `ScaffoldSurfaceReportV1`
- `FakeReadyFindingV1`
- `SuperPassStatusV1`

## Implementation steps

1. Update root README/status docs to reflect the 2026-04-26 snapshot, not 2026-04-25.
2. Add scripts/verify.sh as the single pass gate that chains fmt/check/test/clippy plus local fake-ready checks.
3. Add scripts/assert_no_scaffold_promoted.sh that permits scaffold markers only in explicitly deferred crates and fails if doctor/README claims they are complete.
4. Add a status file that lists every crate as implemented, partial, or scaffold-only with no ambiguous “healthy” wording.
5. Make CI call the same script Codex uses locally.

## Acceptance gates

- bash scripts/verify.sh exists and is referenced by README, AGENTS.md, and CI.
- grep for stale 20260425 metrics either returns none or only explicit historical references.
- Scaffold-only crates are listed in status and doctor as deferred/blocked, never healthy.
- assert_no_fake_completion.sh and assert_no_scaffold_promoted.sh both pass.

## Required tests

- Unit tests for all new artifact constructors and policy decisions.
- Integration tests covering the pass's primary CLI/runtime behavior.
- Golden fixture tests for any schema- or receipt-bearing artifact.
- Regression tests for every bug or counterexample found during the pass.

## Required command gate

```bash
cargo fmt --all --check
cargo check --workspace
cargo test --workspace
cargo clippy --workspace --all-targets --all-features -- -D warnings
bash scripts/verify.sh
```

If a command cannot run in the local environment, Codex must record the exact command and reason in the handoff packet.

## Forbidden shortcuts

- Do not delete scaffold crates to make metrics look cleaner.
- Do not rename scaffolds “experimental” while exposing them as usable.

## Handoff output

At pass completion, create or update:

- pass completion section in `STATUS.md` or equivalent;
- issue matrix rows marked done/blocked/deferred;
- receipts/fixtures/schemas generated by this pass;
- `CodexPacketV1` or a markdown handoff with commands run, failures, files changed, and unresolved blockers.

# P07 — Schema generation, artifact registry, compatibility, and migration law

## Phase

Contracted core

## Purpose

Make all wire-visible artifacts type-owned, schema-generated, versioned, and compatibility-checked.

## Why this pass exists

The contract research pushes type-owned contracts and temporal replay. Historical artifacts must remain readable, so schema compatibility is a release gate.

## Depends on

P06

## Primary crates / surfaces

- `aidens-contracts`
- `aidens-cli`
- `workspace root`
- `schemas`

## Artifact families introduced or hardened

- `ArtifactFamilyRegistryV1`
- `GeneratedSchemaManifestV1`
- `SchemaCompatibilityReportV1`
- `MigrationPlanV1`
- `BackfillReceiptV1`

## Implementation steps

1. Add schema generation command for every public artifact family.
2. Generate schemas into schemas/<family>/<version>.schema.json plus manifest.
3. Add golden JSON fixtures for each artifact type and ensure serde round-trip.
4. Add schema compatibility checks: backward, forward, full, transitive for selected families.
5. Adopt expand/backfill/flip-read/contract migration law for persistent stores.

## Acceptance gates

- cargo run -p aidens-cli -- schemas generate creates deterministic schema files.
- schemas check fails on unregistered artifact family or incompatible breaking change without major bump.
- All old fixtures remain readable after migration path tests.

## Required tests

- Unit tests for all new artifact constructors and policy decisions.
- Integration tests covering the pass's primary CLI/runtime behavior.
- Golden fixture tests for any schema- or receipt-bearing artifact.
- Regression tests for every bug or counterexample found during the pass.

## Required command gate

```bash
cargo fmt --all --check
cargo check --workspace
cargo test --workspace
cargo clippy --workspace --all-targets --all-features -- -D warnings
bash scripts/verify.sh
```

If a command cannot run in the local environment, Codex must record the exact command and reason in the handoff packet.

## Forbidden shortcuts

- Do not hand-maintain schemas that drift from Rust types.
- Do not change interpretation of a V1 artifact without new version.

- issue matrix rows marked done/blocked/deferred;
- receipts/fixtures/schemas generated by this pass;
- `CodexPacketV1` or a markdown handoff with commands run, failures, files changed, and unresolved blockers.

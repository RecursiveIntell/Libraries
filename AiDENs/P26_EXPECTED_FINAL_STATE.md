# P26 Expected Final State

P26 is complete when AiDENs can:

1. validate a declarative `AgentSpecV1`;
2. run a bounded advanced local agent from that spec;
3. ground that agent through canonical memory seam evidence;
4. execute local coding actions through sandbox and permit policy;
5. emit complete RunBundleV3 evidence;
6. inspect/replay the run bundle;
7. abstain/repair honestly on known failure classes;
8. pass P26 verifier and strict package validation;
9. truthfully update support profile.

P26 is not complete if the only improvements are packaging or docs.
